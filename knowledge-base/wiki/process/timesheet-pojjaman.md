# การบันทึก Timesheet ระบบ Pojjaman

## Deadline ส่ง Timesheet
- พนักงานบันทึก Timesheet ใน Pojjaman → หัวหน้าทีม/เจ้าของโปรเจค Approve **ภายในวันที่ 1 ของเดือนถัดไป ก่อน 18:00 น.** [source: raw/hr/การบันทึกข้อมูล Timesheet ระบบ Pojjaman.txt]

## กฎสำคัญ
1. บันทึกข้อมูล**ครบ 8 ชั่วโมงต่อวัน**
2. จำนวนชั่วโมงรวมต้องสอดคล้องกับชั่วโมงทำงานของแต่ละเดือน
3. ถ้ามีลา / OT → ต้องบันทึก Timesheet ครบถ้วนเช่นกัน

## กิจกรรมบริษัทฯ — ลง Timesheet อย่างไร

### 1. All Hands / กิจกรรมบริษัทฯ
- หมวด: **GnA ของทีมตนเอง** > "เบ็ดเตล็ด – ร่วมกิจกรรม / งานอีเว้นท์ต่างๆ ของบริษัท"

### 2. ตรวจสุขภาพประจำปี
- หมวด: **GnA ของทีมตนเอง** > "บุคคล – ไปตรวจสุขภาพ / สวัสดิการพนักงานตรวจสุขภาพ"

## การตรวจชั่วโมงทำงาน
- PROJECT > POJJAMAN REPORT > **Employee Timesheet Checking By Team And Project Report**
