# ขั้นตอนการเบิก OT/เบี้ยเลี้ยง/นักศึกษาฝึกงาน ใน Pojjaman

## Step 1: เตรียมไฟล์
1. ดาวน์โหลดเอกสารจาก SharePoint ของบริษัทฯ
2. บันทึกข้อมูลครบทุกหัวข้อ
3. หมวด **หน่วยงาน (Org.) ต้องตรงกับ Org./Project ใน Pojjaman**
4. บันทึกเป็นไฟล์ **.pdf** [source: raw/hr/ขั้นตอนการเบิกค่าล่วงเวลา ค่าเบี้ยเลี้ยงพนักงาน และค่าเบี้ยเลี้ยงนักศึกษาฝึกงานในระบบ Pojjaman.txt]

## Step 2: สร้างเอกสารใน Pojjaman
1. เข้าระบบ: https://longkongstudio.on.lk/
2. เมนู **Custom Document → Compensation and Benefits** → เลือกหัวข้อ
3. กด New (สีฟ้า) สร้างเอกสาร
4. ระบุข้อมูล:
   - **Org./Project**
   - **Date**: เลือกวันที่ในเดือนที่ทำเบิก (เพื่อให้เลขเอกสารรันถูกต้อง)
     - ตัวอย่าง: ทำเบิกวันที่ 3 ธ.ค. ของเดือน พ.ย. → เลือก 30/11/2025
   - **From Type / From Employee** = ผู้ขอเบิก
   - **To Type / To Employee** = ผู้อนุมัติที่ถือ Role Org_Owner_Approver
   - **Subject/Remark**: "ขอเบิก OT สำหรับรอบ …… (เดือน + ปี พ.ศ.)"
5. แนบไฟล์ใบเบิก: คลิปหนีบกระดาษ → อัปโหลด PDF
   - เบิกเบี้ยเลี้ยง: แนบเอกสารเพิ่ม — ใบเซ็นชื่อ, agenda, นัดหมายใน calendar, รูปภาพ
6. บันทึก:
   - **Save (ปุ่มสีแดง)** → บันทึก ยังไม่ส่ง — ยังแก้ไขได้
   - **Save and Complete (ปุ่มสีฟ้า)** → ส่งไปผู้อนุมัติ L1 ทันที [source: raw/hr/ขั้นตอนการเบิกค่าล่วงเวลา ค่าเบี้ยเลี้ยงพนักงาน และค่าเบี้ยเลี้ยงนักศึกษาฝึกงานในระบบ Pojjaman.txt]

## Step 3: ติดตาม Approval
- พนักงานต้องติดตามให้ L1 อนุมัติภายในรอบ — ถ้าตกรอบเบิก → เบิกไม่ได้
