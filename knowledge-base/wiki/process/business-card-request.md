# ขอทำนามบัตรบริษัท — ขั้นตอนและเงื่อนไข

## เงื่อนไข

### ผ่านทดลองงานแล้ว
- จำเป็นต้องใช้นามบัตร (เช่น ติดต่อลูกค้า) → ขอ Code ได้เลย [source: raw/hr/การขอทำนามบัตรบริษัทฯ.txt]

### ยังอยู่ระหว่างทดลองงาน
1. พนักงานส่งอีเมลแจ้งหัวหน้าทีม + cc HR ระบุความจำเป็น
2. หัวหน้าทีมอนุมัติผ่านอีเมล
3. รับ Code ตามขั้นตอนปกติ

## ขั้นตอนการสั่งทำ
1. กรอกแบบฟอร์มขอ Code: https://forms.office.com/r/e4WiyFw2AX
2. ตรวจสอบ Code ที่ได้ (ลิงก์ SharePoint)
3. สั่งผลิตผ่าน https://corporate.happycard.io

## ข้อยกเว้น
**ตรวจที่อยู่/รายละเอียดให้ถูกต้องก่อนยืนยัน** — ข้อมูลจะไม่สามารถแก้ได้หลังยืนยัน
