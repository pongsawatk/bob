# ลิงค์ประกาศที่มีผลบังคับใช้ — Builk One Group

## จุดรวบรวมประกาศบริษัทฯ
บริษัทรวบรวมประกาศไว้เป็น**แหล่งข้อมูลกลาง** — แบ่ง 2 ส่วน:
- **Active**: ประกาศที่มีผลบังคับใช้ปัจจุบัน
- **Inactive**: ประกาศที่สิ้นสุดการใช้งานแล้ว
