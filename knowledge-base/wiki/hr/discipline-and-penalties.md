# ข้อบังคับฯ — หมวด 8 วินัยและโทษทางวินัย

## ประเภทหลักของการฝ่าฝืนระเบียบวินัย
- **ละเลยไม่ปฏิบัติตามระเบียบ / ละทิ้งหน้าที่ / ขาดงาน** รวมถึงไม่บันทึกเวลา มาสาย ลาผิดระเบียบ [source: raw/hr/ข้อบังคับเกี่ยวกับการทำงาน.txt]
- ประพฤติไม่เหมาะสม — หยอกล้อ ใช้วาจาหยาบคาย ดื่มสุรา สูบบุหรี่นอกพื้นที่ ยาเสพติด
- ก่อการทะเลาะวิวาท / ทำร้ายร่างกาย / พกอาวุธเข้าบริษัท
- เล่นการพนัน / รับสินบน
- **ทุจริต ปลอมแปลงเอกสาร ยักยอก ลักขโมย / กระทำผิดกฎหมาย**
- ปฏิบัติตนเป็นปฏิปักษ์ต่อบริษัท (ให้ร้าย แข่งขันกิจการ เปิดเผยข้อมูลลับ)

## ประเภทโทษทางวินัย (4 ระดับ)
1. **ตักเตือนด้วยวาจา และบันทึกไว้**
2. **ตักเตือนเป็นหนังสือ**
3. **พักงานไม่เกิน 7 วัน** ไม่จ่ายค่าจ้าง + ตักเตือนเป็นหนังสือ
4. **เลิกจ้าง**

## ผู้มีอำนาจลงโทษ
- **ผู้จัดการฝ่ายขึ้นไป**: ตักเตือนด้วยวาจา / หนังสือ
- **กรรมการผู้จัดการ** หรือผู้ได้รับมอบหมาย: ลงโทษได้ทุกประเภท

## พักงานระหว่างสอบสวน
- สิทธิ์สั่งพัก ≤ 7 วัน
- จ่ายค่าจ้าง 50% ระหว่างสอบสวน
- หากไม่ผิด → จ่ายส่วนที่ขาดไป + ดอกเบี้ย 15%/ปี

## มาตรา 119 (พ.ร.บ. คุ้มครองแรงงาน) — เลิกจ้างได้โดยไม่ต้องจ่ายค่าชดเชย
1. **ทุจริตต่อหน้าที่ / กระทำผิดอาญาโดยเจตนาต่อนายจ้าง**
2. จงใจทำให้นายจ้างเสียหาย
3. ประมาทเลินเล่อเสียหายร้ายแรง
4. ฝ่าฝืนข้อบังคับ/ระเบียบ/คำสั่งอันชอบด้วยกฎหมาย หลังตักเตือนเป็นหนังสือ (ยกเว้นรายแรง)
5. **ละทิ้งหน้าที่ ≥ 3 วันทำงานติดต่อกัน** ไม่มีเหตุอันสมควร
6. จำคุกตามคำพิพากษาถึงที่สุด
