# Core Values & Expected Behaviors — Builk One Group

Builk One Group มี **8 Core Values** ที่กำหนดวัฒนธรรมและพฤติกรรมที่คาดหวังของพนักงานทุกคน — สะกดเป็นชื่อย่อประชุม **"BUILK ONE"**

## 1. Be Positive (ทัศนคติเชิงบวก)
มีทัศนคติเชิงบวก สนับสนุนตนเองและผู้อื่น มุ่งเน้นที่การหาทางแก้ไขมากกว่าการมองปัญหา
- เผชิญกับความท้าทายอย่างมีความหวังและมองในแง่ดี
- สนับสนุนและให้กำลังใจเพื่อนร่วมงาน
- มุ่งเน้นที่สิ่งที่ทำได้ ไม่จมอยู่กับอุปสรรค

## 2. Unity (ความเป็นหนึ่งเดียว)
ทำงานร่วมกันเป็นทีมเดียว ให้ความสำคัญกับการร่วมมือและช่วยเหลือกัน
- แบ่งปันความรู้และทรัพยากรกับเพื่อนร่วมงาน
- รับฟังและเคารพความคิดเห็นของทุกคน
- เห็นความสำเร็จของทีมสำคัญกว่าผลประโยชน์ส่วนตัว

## 3. Integrity (ความซื่อสัตย์)
ยึดมั่นในความซื่อสัตย์ โปร่งใส และยุติธรรมในทุกสถานการณ์ แม้ไม่มีใครเห็น
- พูดความจริงและรักษาคำมั่นสัญญา
- ยอมรับข้อผิดพลาดและรับผิดชอบต่อการกระทำของตนเอง
- ปฏิบัติผู้อื่นอย่างเป็นธรรมและให้เกียรติ

## 4. Learn Fast, Move Fast (เรียนรู้เร็ว ลงมือทำเร็ว)
ใฝ่รู้ ปรับตัวเร็ว และลงมือทำอย่างรวดเร็วเพื่อให้ได้ผลลัพธ์
- แสวงหาความรู้และทักษะใหม่ๆ อย่างกระตือรือร้น
- ปรับตัวให้เข้ากับการเปลี่ยนแปลงได้รวดเร็ว
- กล้าตัดสินใจและลงมือทำโดยไม่รีรอเกินความจำเป็น

## 5. Keep Improving (พัฒนาอย่างต่อเนื่อง)
มองหาโอกาสในการพัฒนา ปรับปรุงงานอยู่เสมอ และไม่หยุดแค่คำว่า "พอแล้ว"
- ทบทวนและพัฒนาวิธีการทำงานอย่างสม่ำเสมอ
- ขอและเปิดรับคำแนะนำเพื่อนำไปปรับปรุง
- ตั้งใจทำงานให้ดีที่สุดในทุกเรื่อง

## 6. Ownership (ความเป็นเจ้าของ)
รับผิดชอบต่อหน้าที่และงานของตนเอง ทำงานเสมือนเป็นเจ้าของบริษัท
- รับทั้งความสำเร็จและข้อผิดพลาดด้วยตนเอง
- แก้ไขปัญหาอย่างเชิงรุก
- รับปากแล้วต้องทำให้เสร็จสมบูรณ์

## 7. Nothing Impossible (ไม่มีอะไรที่เป็นไปไม่ได้)
เชื่อว่าไม่มีอะไรที่เป็นไปไม่ได้ พร้อมลุยกับทุกความท้าทาย
- แสดงความมุ่งมั่นและไม่ยอมแพ้ง่ายๆ
- เผชิญปัญหายากด้วยทัศนคติ "ทำได้"
- ส่งต่อแรงบันดาลใจให้ผู้อื่นเชื่อมั่นในศักยภาพ

## 8. Embrace Differences (ยอมรับความแตกต่าง)
เคารพและให้คุณค่ากับความแตกต่าง ทั้งด้านพื้นฐาน ความคิด และมุมมอง
- เปิดใจรับฟังความคิดเห็นที่แตกต่าง
- เคารพในตัวตนของทุกคน
- ใช้ประโยชน์จากความหลากหลายของทีมในการสร้างสรรค์สิ่งใหม่ๆ
