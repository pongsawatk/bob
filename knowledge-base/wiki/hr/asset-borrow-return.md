# ข้อกำหนดการยืม คืนและดูแลรักษาสินทรัพย์บริษัท

## ประเภทสินทรัพย์
- โทรศัพท์มือถือ + ซิม
- คอมพิวเตอร์
- อุปกรณ์ IT (เมาส์ คีย์บอร์ด สายชาร์จ)
- สินทรัพย์อื่นตามบริษัทเห็นสมควร [source: raw/hr/ข้อกำหนดการยืม คืนและการดูแลรักษาสินทรัพย์บริษัท.txt]

## ความรับผิดชอบของพนักงาน
- ดูแลอุปกรณ์ให้อยู่ในสภาพดี ใช้งานได้ปกติ
- **ความเสียหายจากประมาท (ตกหล่น, กระแทก, ของเหลว, ไฟฟ้าลัดวงจร, สูญหาย)**: พนักงานรับผิดชอบค่าซ่อมตามจริง
- ปัญหาฮาร์ดแวร์/ซอฟต์แวร์/เสื่อมตามใช้งานปกติ → บริษัทหรือ IT รับผิดชอบ

## ข้อกำหนดการใช้
- ใช้เพื่อปฏิบัติงานของบริษัทเท่านั้น
- ห้ามติดตั้งอุปกรณ์ หรือซอฟต์แวร์ โดยไม่ได้รับอนุญาต

## การคืนอุปกรณ์
- หลังสิ้นสภาพการเป็นพนักงาน
- บริษัทเรียกคืนเพื่อปรับปรุง/ซ่อมแซม
- ใช้สิทธิสวัสดิการซื้อโน้ตบุ๊ค (ต้องคืนตามเงื่อนไข)
- พนักงานละเมิดข้อกำหนดการใช้ → เรียกคืนทันที + อาจดำเนินการทางวินัย

## สภาพการคืน
- อยู่ในสภาพดี ยกเว้นเสื่อมตามใช้งานปกติ
- เสียหาย/สูญหาย → พนักงานรับผิดชอบ
